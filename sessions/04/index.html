내 홈페이지를 만드는 네 단계.

  1. 재료표 확정
    프로필·지식 자산에서 확인된 정보만 정리합니다.
  2. 채널 소개 맞추기
    대표 정의 문장은 유지하고 채널별 설명을 다듬습니다.
  3. 인계서로 제작
    재료표와 FAQ, 화면 구성을 MD로 넘겨 한 페이지를 만듭니다.
  4. 점검·공개·백업
    5요소와 휴대폰 화면을 확인하고 결과를 개인 공간에 보관합니다.

지난 회차와 이어서

2회차의 지식 자산과 엔티티맵, 3회차의 글쓰기 결과물을 이번 홈페이지의 재료로 사용합니다.

최종 결과물은 홈페이지 주소, 재료표, 인계서와 HTML 백업입니다.

워크북 · ReadRay 1·2

02 / IDEAS TO KEEP

다시 꺼내 볼 여섯 가지.

인사이트·프롬프트·자료실에서 검색합니다.

01KEY INSIGHT

출발점은 확인된 재료표

지식 자산·프로필·엔티티맵을 모아 소개, 전문분야, 경력과 FAQ를 정리합니다. 자료가 없거나 서로 다르면 확인할 항목으로 남깁니다.

근거 · 채팅 21:44 · ReadRay 1

02KEY INSIGHT

첫 문장은 채널마다 같게

이름과 대표 정의 문장을 기준으로 티스토리·링크드인·유튜브를 비교합니다. 첫 문장을 유지하고 뒤의 설명은 각 채널에 맞춥니다.

근거 · 채팅 22:14·22:29

03KEY INSIGHT

도구를 옮길 때는 인계서

확정된 재료표와 FAQ, 원하는 화면 구성을 MD로 정리해 다음 작업창에 전달합니다. 앞선 대화가 자동으로 이어진다고 가정하지 않습니다.

근거 · 채팅 22:37 · ReadRay 2

04KEY INSIGHT

홈페이지는 채널을 묶는 중심

소개와 실적, 질문에 대한 답을 한 페이지에 모으고 실제 운영하는 공개 채널로 연결합니다. 없는 채널의 링크는 만들지 않습니다.

근거 · 채팅 22:34 · 워크북

05KEY INSIGHT

한 번에 한 부분씩 고치기

완성 화면을 보고 소개 문장, 경력 영역, FAQ처럼 고칠 부분을 지정합니다. 디자인을 바꾼 뒤에도 내용과 링크가 유지되는지 확인합니다.

근거 · ReadRay 2 · 워크북

06KEY INSIGHT

공개 주소와 백업까지 확인

공개 후 다른 기기에서 열어 보고, 휴대폰 표시와 링크를 점검합니다. 재료표·인계서·HTML은 개인 저장 공간에 보관합니다.

근거 · ReadRay 2 · 워크북

검색 결과가 없습니다. 다른 단어로 검색해 보세요.

같은 소개가 여러 채널을 연결합니다.

엔티티 재료표에 담을 것

  • 이름 · 대표 정의 문장 · 직함·소속
  • 한 줄 소개 · 전문분야 3개
  • 대표 경력 5개 · 대표 실적
  • 자주 묻는 질문 5개 · 핵심 키워드 10개

없는 내용이나 서로 다른 수치는 [확인 필요]로 표시하고 본인이 확인합니다. 개인 연락처·집 주소·주민번호는 제외합니다.

채널을 맞추는 순서

  1. 실제 채널 주소와 현재 소개 수집
  2. 재료표의 이름·정의 문장과 대조
  3. 첫 문장은 유지하고 설명 확장
  4. 링크와 공개 내용을 직접 확인

운영하지 않는 채널은 ‘없음’으로 표시하세요. 소개를 통일하는 것만으로 AI 추천·인용이 보장되지는 않습니다.

채팅 21:44 · 22:14 · 22:29

디자인을 고친 뒤에도, 이 다섯 가지.

  1. 누구인가 — 첫 화면에 이름과 대표 정의 문장
  2. 무엇을 하나 — 전문분야·경력·실적
  3. 무엇을 묻나 — FAQ 5개와 질문 바로 아래 답
  4. 어디에 또 있나 — 실제 운영 채널 링크
  5. 보이지 않는 이름표 — JSON-LD Person·FAQPage, meta description, 업데이트 날짜

채팅 23:05 · 워크북
5요소는 강의의 구성 점검 기준이며 검색 노출 점수가 아닙니다.

메뉴를 못 찾았을 때

확정 재료표와 FAQ를 담은 MD 인계서를 만듭니다. 제작 도구의 새 작업창에 파일을 첨부하거나 내용을 붙여 넣어 이어갑니다.

워크북의 추가 트랙

가게 운영자는 소개·기본정보·손님 질문을, 개인 전문가는 소개·저작 목록·의뢰인 질문을 정리합니다. GitHub Pages와 llms.txt·사이트맵·robots.txt는 도전 트랙입니다.

채팅 22:37 · 워크북 · ReadRay 2

06 / COPY & TRY

강의에서 실제로 쓴 요청문.

강사가 채팅에 올린 원문 7개입니다. 대괄호와 빈칸은 자신의 확인된 정보로 채우세요. 채팅의 역할 설정 문구는 AI에게 주는 지시이며 실제 경력이나 성과를 뜻하지 않습니다.

첨부한 지식 자산 문서와 홈페이지 자료 목록, 아래 정보로 나의 엔티티 재료표를 만들어 줘.

없는 내용은 [확인 필요], 주민번호·집 주소·개인 연락처 제외

03강사 채팅 원문 · 22:14채널별 이름·소개 비교하기＋
아래는 내 채널 주소와 지금 쓰고 있는 이름 · 한 줄 소개입니다.
- 티스토리: [주소] / [블로그명] / [소개]
- 링크드인: [주소 또는 없음] / [헤드라인]
- 유튜브: [주소 또는 없음] / [채널명] / [설명 첫 문장]
재료표의 이름 · 대표 정의 문장과 비교해 채널마다 다른 곳을 표로 보여 주고,
채널별로 바꿔 넣을 문장을 대표 정의 문장 그대로 제안해 주세요.
04강사 채팅 원문 · 22:29채널별 소개글 완성하기＋
소개글의 첫문장을 유지하고 이어서 채널별로 소개글을 GEO최적화로 완성해서 코드블럭으로 만들어줘. 복붙해서 수정할 수 있게
05강사 채팅 원문 · 22:34Sites 홈페이지 제작 요청＋
@Sites위 재료표로 나의 GEO 홈페이지 website를 만들어 줘.
1. 첫 화면: 이름 + 대표 정의 문장
2. 전문분야 3개 · 대표 경력 · 대표 실적
3. FAQ 5개: 질문 바로 아래 두괄식 답
4. 푸터: 티스토리 · 링크드인 · 유튜브 링크 (없는 채널은 빼기)
5. 보이지 않는 이름표: JSON-LD Person · FAQPage, meta description, 최종 업데이트 날짜(오늘)
6. 한국어, 휴대폰에서도 읽기 쉬운 한 페이지
재료표에 없는 경력·숫자는 넣지 말고 [확인 필요]로 표시해 줘.
06강사 채팅 원문 · 22:37다른 작업창으로 넘길 MD 인계서＋
sites 에 가서 직접 할 수 있도록 재료표가 있는 인계서를 md파일로 만들어줘
07강사 채팅 원문 · 23:05홈페이지 5요소 점검하기＋
첨부한 홈페이지 코드를 아래 5요소로 점검해 줘.
1. 누구인가: 첫 화면에 이름 + 대표 정의 문장
2. 무엇을 하나: 전문분야 3개 · 경력 · 실적
3. 무엇을 묻나: FAQ 5개 · 두괄식 답
4. 어디에 또 있나: 푸터에 유튜브 · 티스토리 · 링크드인
5. 보이지 않는 이름표: JSON-LD(Person · FAQPage) · meta description · 업데이트 날짜
항목별 ○/× 표로 정리하고, ×인 항목은 고칠 문장만 알려 줘.
