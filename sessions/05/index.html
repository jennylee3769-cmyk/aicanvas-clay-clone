  1. 작업 방과 규칙 → 자료·결과물·보관, AGENTS.md
  2. 내 사실을 재료로 → 엔티티 재료표와 확인 필요 항목
  3. 글과 이미지를 결과로 → GEO 지침, MD·HTML, 이미지 파일
