자료에서 주제로, 주제에서 관점으로.

  1. 지난 회차 엔티티맵을 첨부합니다.
  2. 블로그·칼럼·보도자료에 쓸 주제 3개를 표로 추천받습니다.
  3. 블로그는 독자의 질문, 칼럼은 나의 주장, 보도자료는 실제 사건으로 구분합니다.
  4. 블로그 설명과 작성자 정보는 엔티티맵의 확인된 정보와 맞춥니다.

칼럼 설계 체크

독자 · 핵심 메시지 · 주장 · 근거 · 도입 사례 · 분량을 먼저 확인합니다. 가상 사례는 가상이라고 표시하고, 실제 경험과 섞지 않습니다.

ReadRay 2 주제 선정 · ReadRay 3 칼럼 설계

작성 모드가 달라도, 검수는 끝까지.

GEO 블로그 7단계

  1. 질문형 제목 후보 3개
  2. 첫 문단에 1~2문장 직답
  3. 질문형 H2 소제목 3~5개
  4. 각 소제목 아래 두괄식 직답
  5. 연도·기관·출처가 있는 근거
  6. FAQ 3~5개
  7. 작성자 정보와 작성일

HTML 실습 순서

HTML 코드를 요청 → 티스토리 HTML 모드에 붙여넣기 → 기본 모드에서 실제 이미지 삽입 → 설명·태그 확인 → 미리보기 → 공개 또는 예약.

이미지 생성용 묘사는 이미지 파일 자체가 아닙니다. 이미지를 생성·저장한 뒤 삽입하세요. 칼럼은 추천 문구와 편집 메모를 정리하고, 주장과 근거를 검토합니다.
